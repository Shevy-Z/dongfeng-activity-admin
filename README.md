# 东风日产活动运营后台原型

根据四张后台页面参考图构建的前端交互原型，包含活动列表、新增活动、卡券列表和新增/编辑卡券四个核心页面。

## 功能

- 活动查询、创建、启用/禁用、复制、删除和 CSV 导出
- 卡券查询、创建、编辑、投放/暂停和 CSV 导出
- 浏览器 `localStorage` 本地持久化
- 桌面端与移动端响应式布局
- 无构建依赖，直接打开 `dist/index.html` 或通过静态服务器运行

## 本地运行

```bash
python3 -m http.server 4173 -d dist
```

然后打开 <http://localhost:4173>。

> 本项目为交互式产品原型，不连接真实生产接口或数据库。
